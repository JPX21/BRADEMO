# Exercício 5 - Flutter

Projeto referente ao exercício 5 da aula de Flutter.

## Como usar

1. Extraia este ZIP.
2. Abra a pasta no VS Code.
3. No terminal, execute:
   flutter pub get
4. Execute:
   flutter run

A imagem usada está em `assets/lake.png` e já está configurada no `pubspec.yaml`.
